Comment obtenir ma clé ?
  1. Sur github.com, ouvrez Settings (photo de profil en haut à droite).
  2. Tout en bas à gauche : Developer settings, puis Personal access tokens, puis Fine-grained tokens.
  3. Cliquez Generate new token. Nom : « ZenTech admin ». Expiration : 1 an.
  4. Repository access : Only select repositories, puis choisissez le dépôt du site.
  5. Permissions → Contents : Read and write.
  6. Cliquez Generate token, copiez la clé et collez-la ci-dessus.

Gardez cette clé secrète : elle permet de modifier le site. Vous pouvez la supprimer à tout moment sur GitHub.

Plan du site à déclarer dans Google Search Console
Où trouver ce code ?
  1. Ouvrez search.google.com/search-console avec le compte Google de la boutique.
  2. Ajoutez une propriété, choisissez Préfixe de l'URL et collez l'adresse du site.
  3. Choisissez la méthode Balise HTML, copiez la balise et collez-la ici.
  4. Enregistrez, publiez, attendez une minute, puis cliquez Valider chez Google.
  5. Dans Sitemaps, ajoutez l'adresse du plan du site ci-dessus.
À quoi ça sert ?

Pour voir le nombre de visiteurs, les pages les plus vues et d'où viennent vos clients. Créez un compte sur analytics.google.com, ajoutez un flux de données « Web » avec l'adresse du site, puis copiez l'ID de mesure (il commence par G-).
